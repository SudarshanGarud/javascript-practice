# JavaScript Practice

This repository contains a collection of JavaScript projects I built while independently learning frontend development and interactive web behavior.

The goal of these projects was to strengthen my understanding of JavaScript fundamentals through hands-on implementation and experimentation.

## What I Learned

Before building these projects, I spent time learning JavaScript concepts independently and then applied them through practical projects and UI interactions.

Through this repository, I explored:

- DOM manipulation
- event handling
- conditional logic
- functions and reusable logic
- working with arrays and objects
- dynamic UI updates
- application state handling
- form interactions
- Fetch API and asynchronous JavaScript
- working with external APIs
- responsive frontend behavior
- structuring interactive web applications

## Projects Included

### Counter App
Built to practice state updates, event handling, and DOM manipulation through simple interactive controls.

### To-Do App
Focused on managing dynamic UI updates, handling user input, and working with interactive task based functionality.

### Weather App
Built to understand API integration, asynchronous JavaScript, and displaying dynamic data from external sources.

### Expense Tracker App
Focused on handling application logic, updating data dynamically, and organizing user generated information within the interface.

### Quiz App
Built to practice conditional rendering, interaction logic, user feedback, and dynamic content updates.

## Workflow

For each project, I first understood the concepts I wanted to practice and then applied them while building the application from scratch.

This helped me move beyond theory and gain practical experience with JavaScript driven interactions and frontend behavior.

## Reflection

These projects helped me better understand how JavaScript powers interactive user experiences and dynamic frontend applications.

More importantly, building them independently helped me improve my problem solving approach, understand implementation logic more clearly, and become more comfortable translating concepts into working interfaces.
